# Finance AI

Локальное приложение для персонального управления финансами с AI-помощником.
Данные хранятся только на вашем компьютере в файле SQLite.

**Текущее состояние: этап 2F — не интегрирована нейросеть.**

---

## Запуск на Windows

Требуется Python 3.11+ и Node.js 20+.

```
setup.bat     — один раз: venv, зависимости, .env, миграции, npm install
start.bat     — каждый день: поднимает backend и frontend, открывает браузер
```

После `start.bat`:

| | |
|---|---|
| Интерфейс | http://localhost:5173 |
| API | http://127.0.0.1:8000 |
| Документация API | http://127.0.0.1:8000/docs |

Вспомогательные скрипты в `scripts/`:

* `run_tests.bat` — тесты backend
* `migrate.bat` — применить миграции; с аргументом создаёт новую
* `run_backend.bat` / `run_frontend.bat` — запуск по отдельности

## Финансовый контекст

`GET /api/v1/context` — версионированная read-only сводка финансов (счета, потоки по месяцам, долги, бюджеты, цели, регулярные операции, предстоящие события, показатели) для будущего локального ассистента. Валюты не смешиваются и не конвертируются, свободный текст не включается, запрос ничего не пишет в БД. Структура, формулы показателей и пример ответа — [docs/financial-context.md](docs/financial-context.md).

## Принципы

**Деньги — целые числа.** Сумма хранится как целое число копеек. `float`
запрещён на уровне типов: `Money.from_major(10.55, "RUB")` выбрасывает
`TypeError`. Это защищает от накопления ошибки округления, из-за которой
баланс расходится с историей операций.

**Расчёты — в Financial Engine.** Пакет `app/engine/` не импортирует ни
FastAPI, ни SQLAlchemy. Он принимает простые структуры и возвращает
результаты, поэтому его можно тестировать без базы. Роутеры остаются тонкими.

**AI не считает и не действует.** Языковая модель получает только готовый
`FinancialSnapshot` с уже посчитанными числами, а её предложения требуют
явного подтверждения пользователем. Ключ API живёт в `backend/.env` и никогда
не попадает во frontend.

**Мультивалютность заложена в модель.** Каждая сумма несёт валюту, операции
между разными валютами запрещены. В MVP пользователь работает только с RUB;
курсы и конвертация не реализуются.

## Разработка

```
scripts\run_tests.bat              тесты
scripts\migrate.bat "описание"     новая миграция
cd frontend && npm run typecheck   проверка типов
```

Резервная копия — просто скопируйте `backend/data/finance.db`.
Экспорт в JSON/CSV появится вместе с данными на следующих этапах.
